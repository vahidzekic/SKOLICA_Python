# Predavanje 1 — Uslovno Grananje (if/elif/else)

## 1.1 IF statement

```python
if uslov:
    # blok koji se izvršava ako je uslov True
```

## 1.2 Operatori poređenja

| Operator | Značenje |
|---|---|
| `==` | Jednako |
| `!=` | Nije jednako |
| `<`, `>` | Manje, veće |
| `<=`, `>=` | Manje/veće ili jednako |
| `in` | Sadržan u kolekciji |
| `is` | Identičan objekat |

## 1.3 Logički operatori

| Operator | Opis |
|---|---|
| `and` | Oba uslova True |
| `or` | Bar jedan True |
| `not` | Negacija |

## 1.4 Ternary operator

```python
rezultat = "pozitivan" if broj > 0 else "negativan"
```

## Rezime
- `if`, `elif`, `else` za grananje
- Indentacija definiše blok koda
- Ternary: `a if uslov else b`

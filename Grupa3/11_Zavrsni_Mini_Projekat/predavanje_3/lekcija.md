# Predavanje 3 — Kompletna CLI Aplikacija

## 3.1 Meni sistem

Koristi `while True` + `input()` za interaktivni meni.

## 3.2 Integracija modula

Sve komponente rade zajedno:
- `Kontakt` klasa za modelovanje
- `KontaktStorage` za persistenciju
- RegEx validacija
- Try/except za robustnost

## 3.3 Finalni projekat

Funkcionalan CLI alat sa:
1. Dodavanje kontakta (sa validacijom)
2. Pregled svih kontakata
3. Pretraga kontakata
4. Brisanje kontakta
5. Izlaz

## Rezime
- CLI aplikacija integriše OOP, fajlove, regex, error handling
- Sentinel petlja (`while True` + `break`) za meni
- Modularni kod: odvojene klase za model i storage

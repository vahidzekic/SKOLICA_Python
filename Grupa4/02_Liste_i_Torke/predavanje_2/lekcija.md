## Comprehension
```python
[izraz for x in seq if uslov]
```

## Korisne funkcije
- `enumerate()` — indeks + element
- `zip()` — paralelna iteracija
- `any()` / `all()` — logičke provere

## Rezime
- Comprehension zamenjuje for + append
- `enumerate()` za indeksirane petlje

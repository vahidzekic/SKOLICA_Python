# Predavanje 1 — Zdravo Python: Instalacija i Prvo Pokretanje

## 1.1 Zašto Python?

Python se koristi u:
- **Web razvoju** (Django, Flask)
- **Data Science** (Pandas, NumPy)
- **Mašinsko učenje** (TensorFlow, PyTorch)
- **Automatizacija** (skripting, DevOps)

## 1.2 Pokretanje

```bash
python3 --version
python3 moj_program.py
```

## 1.3 print()

```python
print("Zdravo!")
print("A", "B", sep="-")   # A-B
print("Tekst", end=" ")    # Bez novog reda
```

## 1.4 Komentari
- `#` za jednolinijske
- `\"\"\"...\"\"\"` za višelinijske (docstring)

## Rezime
- Python je interpretirani, dinamički tipiziran jezik
- `print()` za ispis na konzolu

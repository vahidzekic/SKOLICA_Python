# Predavanje 2 — Promenljive, Tipovi i f-string

## 2.1 Kreiranje promenljivih

```python
grad = "Novi Pazar"     # str
stanovnika = 100000     # int
visina = 496.0          # float
prestonica = False      # bool
```

## 2.2 Četiri osnovna tipa

| Tip | Klasa | Primer |
|---|---|---|
| Ceo broj | `int` | `42` |
| Decimalni | `float` | `3.14` |
| Tekst | `str` | `"zdravo"` |
| Logički | `bool` | `True` |

## 2.3 Konverzija: `int()`, `float()`, `str()`, `bool()`

## 2.4 f-string formatiranje
```python
print(f"{ime}, {godine} god.")
print(f"PI: {3.14159:.2f}")
```

## Rezime
- `type()` za proveru tipa
- f-string je najčitljiviji format

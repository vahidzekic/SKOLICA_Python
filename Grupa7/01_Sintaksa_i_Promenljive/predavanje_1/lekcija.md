# Predavanje 1 — Uvod u Python

## 1.1 Python — jezik budućnosti
- Najpopularniji jezik 2024. (TIOBE Index)
- Koristi se: AI, web, automatizacija, nauka
- Filozofija: "Readability counts" (PEP 20)

## 1.2 Pokretanje
```bash
python3 --version
python3 program.py
```

## 1.3 print() — komunikacija sa korisnikom
```python
print("Zdravo, svete!")
print("Lat:", 44.01, "Lon:", 20.92)
print("A", "B", sep=" → ")
```

## 1.4 Komentari
- `#` jednolinijski
- `\"\"\"...\"\"\"` višelinijski (docstring)

## Rezime
- Python: čitljiv, dinamički tipiziran, indentacija je sintaksa
- `print()` — osnovna izlazna funkcija

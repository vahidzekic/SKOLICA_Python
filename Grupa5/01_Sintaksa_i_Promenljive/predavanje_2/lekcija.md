# Predavanje 2 — Promenljive i Tipovi Podataka

## 2.1 Kreiranje
```python
sport = "Fudbal"    # str
golova = 3           # int
prosek = 2.45        # float
aktivan = True       # bool
```

## 2.2 Tipovi
| Tip | Klasa | Primer |
|---|---|---|
| Tekst | `str` | `"zdravo"` |
| Ceo broj | `int` | `42` |
| Decimalni | `float` | `3.14` |
| Logički | `bool` | `True` |

## 2.3 type() i konverzija
`int()`, `float()`, `str()`, `bool()`

## 2.4 f-string
```python
print(f"{ime} ima {godine} godina")
```

## Rezime
- Tip se određuje automatski
- `type()` za proveru, `int()/float()/str()` za konverziju
